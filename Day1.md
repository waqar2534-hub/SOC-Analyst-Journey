## What I Learned Today


Today I started learning the basics of Linux and set up my cybersecurity learning environment. I understood what Linux is and why it is important in cybersecurity. I practiced basic terminal commands and learned how to navigate the file system.

I used commands like `ls`, `cd`, `pwd`, and `cat` to explore directories and files. These commands helped me understand how Linux works in a command-line environment.

I also completed TryHackMe: Linux Fundamentals Part 1, where I applied my basic knowledge in a practical lab environment.
